    Tutorial Series — IBM VPC File Pool CSI Driver¶

    Hands-on tutorials covering every major capability of the pool CSI driver. Each part is self-contained with its own setup and cleanup — follow them in any order after Part 1. The words used here are defined in CONTEXT.md.

    Cluster: ROKS (OpenShift Virtualization enabled)

    Tutorials¶

    Part Tutorial What You'll Learn
    1 Pool Creation, PVCs, and KubeVirt VMs Create a pool, provision PVCs, launch a VM with NFS-backed boot and data disks
    2 Snapshots and Clones Point-in-time snapshots, restore from snapshot, clones (asynchronous, Job-based)
    3 Group Snapshots and Hooks Group snapshots are not active; what to use instead, and lifecycle hooks on replication
    4 Pool Configuration Multi-tier pools, spread vs binpack strategies, auto-expansion, share draining
    5 Golden Images CDI native mode and custom syncer for automatic KubeVirt golden image provisioning
    6 Replication and Failover Direct NFS and driver-to-driver cross-region replication, pause/resume, failover CLI
    7 Monitoring Prometheus metrics (37 metrics), ServiceMonitor, alerting rules, Grafana dashboard
    8 Migration and Console Plugin PVC migration from stock driver, OpenShift console plugin walkthrough
    9 COS Bucket for Backups Locked COS bucket, a key that cannot delete or unlock, a CBR rule that limits it to the cluster
    10 Backup and Restore Back up a volume on a schedule to a snapshot pool, list the moments, restore one, delete backups
    11 Instant VM Snapshots Turn on the Sidecar gate, snapshot a running VM in seconds, merge, restore, flatten
    12 Replicating Running VMs Copy a running VM with all disks at one moment to a second cluster through a receiver
    13 Failover of Running VMs Plan, rewind and fail over replicated VMs with kubectl failover
    14 Restore a Snapshot in the Console Make a snapshot and restore it to a new PVC in the OpenShift console
    15 Make a VM from the Catalog on a Pool Pick a catalog image and an instance type, choose the pool's StorageClass for the boot disk, and let CDI copy the image
    16 Backups, Clones and Replication Setup in the Console Schedule and restore backups, clone a volume, and set up a replication receiver in the console

    Reading Order¶

    Parts 2-16 are independent of each other, except that Part 13 follows Part 12. Pick whichever is relevant to your use case.

    Prerequisites (All Parts)¶

    Every tutorial assumes:

    1. ROKS or ROVS cluster with OpenShift Virtualization enabled (for VM tutorials)
    2. CSI driver deployed — controller and node pods running: 
      oc get pods -n kube-system -l app.kubernetes.io/name=ibm-vpc-file-pool-csi
    3. IBM Cloud CLI with VPC infrastructure plugin (ibmcloud is)
    4. oc and virtctl CLI tools installed
