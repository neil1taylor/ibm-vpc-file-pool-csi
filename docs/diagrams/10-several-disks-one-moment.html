Several Disks, One Moment

A VM can have more than one disk. Here the VM has a system disk and a data disk. A program in the VM writes file n on the data disk, then writes a log line about it on the system disk. This page takes a snapshot two ways and restores a new VM from each. The log must never name a file that is missing.

Method:

A tick is one short step of the VM's work. Let the VM work for a few ticks, take the snapshot with each method (press Start again between them), then restore and compare. A block with a white outline is the last one in that snapshot.

What you see

a file on the data disk a log line on the system disk !n = a log line for a file the data disk does not have not written yet last block in the snapshot
VM time: tick 0 Data disk snapshot: none System disk snapshot: none Log lines naming a missing file after restore: not restored

How the driver does this today

  • KubeVirt asks for one snapshot per disk. It does not ask for a group of disks.
  • The driver copies all the pool disks of the VM at one moment, when the first disk's request arrives. The requests for the other disks join that copy.
  • The guest is frozen once, so its pending writes reach the disks first. If the guest cannot freeze, the snapshot is marked crash consistent (as after a power cut) and it says so in its status.
  • With instant snapshots (Experimental, off by default), OpenShift freezes the guest once and the driver starts a new file on every disk inside that freeze.
  • One cost: a snapshot of one disk of a VM with several disks also copies the other disks to temporary files. They are deleted after 10 minutes if no snapshot claims them. Each share needs room for them.
  • A disk that is not on a pool is not part of the moment.
  • A group snapshot record (VolumeGroupSnapshot) exists, but it is switched off. A VM does not need it.

Lab result, 21 October 2026, before this was fixed: the two disks were copied 80 seconds apart, and 725 of 1,154 logged files were missing from the data disk of the restored VM. Each disk was sound on its own. They did not fit each other.
