VM Disk Snapshot Chain

A VM's disk is one file on a shared file share. This page shows what happens to that file when you take a snapshot. Each block below is one piece of the disk. The letter is what is stored in it.

Try: take a snapshot, then change data. The snapshot keeps the old letters. The VM sees the new ones. A block with a white outline was just changed.
