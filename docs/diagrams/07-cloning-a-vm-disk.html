Cloning a VM disk

A clone is a new volume made from an existing one. The file share cannot copy a file by pointing to it, so the clone is a real copy of every byte. That takes time. The driver makes the new volume at once, but the VM must wait until the copy is complete. This waiting is called the clone gate. Press the buttons in order.

    Why it takes time

    A file share keeps no shortcut for copying a file. The copy Job reads every byte from the source and writes it to the clone, so the time grows with the size of the disk. A clone on another share is slower, because the data crosses the network twice. The driver prefers the source's share when it has room.

    Stop the source VM before you clone it. If the VM writes while the file is copied, the clone mixes different moments of the disk and may not boot.
