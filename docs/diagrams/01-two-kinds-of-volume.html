Two kinds of volume

Every volume is a folder on a shared file share. There are two kinds. A plain volume is a folder of files that pods use. A VM volume holds one image file per disk, called disk.img. The driver copies each kind in its own way. Press the buttons in order and watch the two cards.

file a file of a plain volume (name, then version: v1, v2) A1 a piece of a VM disk (letter = which piece, number = version) v2 white outline = changed or sent by the last action same dashed = empty, or a link to the latest copy (no extra space)

At a glance

Plain volumeVM volume
Snapshot (same share)A Job copies the folder (cp -a). It takes longer for more data. Only as consistent as the files.Running VM: QEMU copies all the VM's disks at one moment. Instant snapshots copy nothing, but are Experimental and need the KubeVirt Sidecar gate.
Backup (backup pool)Files are copied. Each earlier moment is a folder of hard links. Reported as FileCopy.One whole disk.img, plus undo files for earlier moments. All disks of the VM show one moment. FileSystemConsistent if the guest was frozen, else CrashConsistent.
Replication (another cluster)Files are copied. By default only the latest copy is kept.QEMU copy: whole disk the first time, then only changed blocks. Restore points are kept 24 hours by default.

A VM that is switched off is copied as a folder, like a plain volume.
