How a Pod Gets Its Volume

A pod runs on a worker node. Its volume is a folder on a share in the VPC. The driver's node agent runs on every node. It connects the node to the share (an NFS mount), then gives each pod only its own folder (a bind mount). This page starts and stops four pods so you can see each step.

Press Next step to follow the story, or use the Start and Stop buttons on the pods in any order. Volume ccc is a clone: its data is still being copied, so a pod cannot use it yet. A block with a white outline is new.
