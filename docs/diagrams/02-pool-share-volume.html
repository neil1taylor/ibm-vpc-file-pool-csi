Pool, Share and Volume

A share is one big NFS folder that IBM Cloud runs for you. A volume is one small folder inside a share. A pool is the set of shares the driver manages together. This page shows how the driver picks the share for a new volume.

Pool settings:

Try: make three 10 GB volumes with spread, then start again and do the same with binpack. Then switch auto-expand on and fill the pool. The shares here hold 100 GB each so the page stays small. A block with a white outline is new.

The driver's records · one SubVolume per volume

Making a volume only writes one line here. It says which share holds the volume, which folder it uses and how big it is. The real folder name is /pvcs/pvc- plus a 36-character id. This page shortens it.
