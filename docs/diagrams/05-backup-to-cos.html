Backup to COS

A backup keeps many moments of a volume. It lives on a separate share in your own VPC. That does not help if the whole VPC is lost. So the driver can also send each backup to an IBM Cloud Object Storage (COS) bucket, locked so that nobody can delete it early. This feature is Experimental. Press Next step, then try the extra buttons.

      A Compliance lock cannot be undone, not even by IBM. Locked data is billed until its lock ends, also after you delete the policy. The shortest lock the driver allows is 25 hours.
